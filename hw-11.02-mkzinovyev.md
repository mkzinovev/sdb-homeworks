### Ответы на задание 1. Кеширование

Кеширование помогает решить следующие проблемы:

1. **Снижение нагрузки на базу данных**  
    Часто запрашиваемые данные можно хранить в кеше, чтобы не обращаться каждый раз к основной БД.
    
2. **Ускорение ответа приложения**  
    Данные из кеша обычно читаются быстрее, чем из базы данных, файловой системы или внешнего API.
    
3. **Снижение нагрузки на внешние сервисы**  
    Если приложение часто обращается к стороннему API, результат можно временно сохранять в кеше.
    
4. **Оптимизация тяжёлых вычислений**  
    Результаты сложных расчётов можно сохранить и переиспользовать, а не вычислять заново.
    
5. **Сглаживание пиковых нагрузок**  
    Во время высокой активности пользователей кеш позволяет быстрее отдавать популярные данные.
    
6. **Хранение временных данных**  
    Например, сессии пользователей, одноразовые токены, временные коды подтверждения, промежуточные результаты.

### Ответ задание 3. Удаление по TTL в Memcached

Запишем несколько ключей в Memcached с TTL 5 секунд.

Команда:

```bash
{
  printf "set key1 0 5 5\r\nvalue\r\n"
  printf "set key2 0 5 6\r\nvalue2\r\n"
  printf "get key1 key2\r\n"
  sleep 6
  printf "get key1 key2\r\n"
  printf "quit\r\n"
} | nc localhost 11211
```

Что здесь происходит:

```text
set key1 0 5 5
```

Где:

```text
key1  — имя ключа
0     — flags
5     — TTL в секундах
5     — размер значения в байтах
value — значение
```

Ожидаемый результат до истечения TTL:

```text
STORED
STORED
VALUE key1 0 5
value
VALUE key2 0 6
value2
END
```

Через 6 секунд ключи удаляются, и второй `get` вернёт только:

```text
END
```

### Задание 5*. Работа с числами 

Запишите в Redis ключ key5 со значением типа "int" равным числу 5. Увеличьте его на 5, чтобы в итоге в значении лежало число 10.  

*Приведите скриншот, где будут проделаны все операции и будет видно, что значение key5 стало равно 10.*

---

### Ответ задание 5*. Работа с числами

В Redis значения хранятся как строки, но если значение является числом, Redis позволяет выполнять над ним арифметические операции.

Выполним:

```bash
redis-cli
```

Далее:

```redis
SET key5 5
GET key5
INCRBY key5 5
GET key5
```

Ожидаемый вывод:

```text
OK
"5"
(integer) 10
"10"

```

Итог: значение ключа `key5` стало равно `10`.
